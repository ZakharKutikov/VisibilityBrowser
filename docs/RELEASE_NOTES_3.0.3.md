# Visibility Browser 3.0.3

## Что нового

- **Автообновление.** Через несколько секунд после запуска браузер смотрит на GitHub, нет ли новой версии. Если есть, в углу окна появляется карточка «Доступна версия X». Кнопка «Обновить» скачивает установщик, проверяет его контрольную сумму SHA-256 по данным GitHub и ставит поверх. Потом остаётся нажать «Перезапустить». Контрольная сумма не совпала или файл не скачался: ничего не запускается, карточка покажет ошибку.
- Версия на новой вкладке: 3.0.3.

## Как обновиться с 3.0.2 и ниже

В этих версиях автообновления нет, поэтому один раз нужно скачать `Visibility-3.0.3-Setup.exe` и запустить поверх. Дальше браузер будет предлагать обновления сам.

## Что осталось

- Схема `chrome://` в адресной строке.
- Поиск по умолчанию — Google, меняется в настройках.
- Отключить проверку обновлений пока нельзя.

## Требования

Windows 10 или 11, 64 бит.
