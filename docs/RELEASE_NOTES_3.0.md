# Visibility Browser 3.0 (экспериментальная)

Visibility перешёл с Electron на собственную сборку Chromium, исходный код открыт. Версия экспериментальная: возможны вылеты и недоделки. Стабильная версия — 2.1.

## Главное

- **Новый движок.** Visibility 3.0 — форк Chromium 158. Сайты, видео, звонки и DevTools работают так же, как в Chrome, без прослойки Electron.
- **Открытый код.** Все наши изменения Chromium, скрипты сборки и интерфейс лежат в этом репозитории под лицензией MIT. Собрать браузер самому можно по инструкции [docs/BUILD.md](BUILD.md).
- **Знакомый интерфейс.** Окно, вкладки, адресная строка, меню, настройки, история, загрузки и панель VPN написаны заново в стиле 2.1. Рамка стала компактнее: две строки вместо четырёх, страница лежит на отдельном листе.
- **Расширения Chrome.** Работают расширения из Chrome Web Store и распакованные из папки.
- **Встроенный VPN.** VLESS, Trojan и Shadowsocks по ссылкам и подпискам, раздельная маршрутизация. Ядро Xray скачивается с GitHub при первом включении.
- **Новая вкладка.** Часы с приветствием, поиск с подсказками, ярлыки, погода и недавние сайты.
- **Экономия памяти включена по умолчанию.** Вкладки, которыми давно не пользовались, выгружаются из памяти, как фоновые вкладки в 2.1. Вкладки со звуком не выгружаются. Выключить можно в настройках.
- **Свои иконки** на панели задач, в диспетчере задач, у ярлыков, файлов и установщика.

## Переход с 2.1

- 3.0 ставится отдельно от 2.1, в свою папку и со своим профилем. Версию 2.1 можно удалить после установки.
- Закладки, история и настройки из 2.1 автоматически не переносятся. Закладки можно сохранить заранее: в 2.1 «Настройки → Экспорт закладок» сохраняет их в JSON-файл.
- Расширения формата `.visibility` от 2.1 в 3.0 не работают. Вместо них поддерживаются обычные расширения Chrome.

## Известные ограничения

- Часть сервисов Google из Chromium ещё не убрана: работа идёт, план в [chromium/design/STRIP.md](../chromium/design/STRIP.md).
- Поиск по странице и поиск по вкладкам пока выглядят как в Chromium.

## Требования

Windows 10 или 11, 64 бит.
