# Visibility Browser 3.0.2

## Что нового

- **Своё окно «Поиск по странице».** Плавающая карточка в палитре Visibility с счётчиком совпадений, кнопками «назад/вперёд» и закрытием по Esc. Раньше это было стандартное окно Chromium.
- **Свой «Поиск по вкладкам».** Открывается по Ctrl+Shift+A: фильтр по названию и адресу, стрелки и Enter для перехода. Раньше эта функция не открывалась вообще.
- **Без входа в аккаунт Google.** Убраны раздел «Я и Google», синхронизация и предложение синхронизировать историю. Страница настроек открывается на «Внешнем виде», раздел «ИИ в Visibility» убран.
- **Свой логотип** в шапке страниц настроек, расширений, истории и загрузок и в пункте «О Visibility». Раньше там был логотип Chromium.
- **«О Visibility»:** вместо «Сборка для разработчиков» теперь «Сборка Visibility». Ссылка на проект Chromium снова называется Chromium (раньше из-за переименования подписывалась «Visibility»). Ссылка на «Интернет-магазин Chrome» тоже называется честно: расширения ставятся именно оттуда.
- Версия на новой вкладке: 3.0.2.

## Что осталось

- Схема `chrome://` в адресной строке. Менять её рискованно для работы браузера.
- Поиск по умолчанию: Google. Сменить можно в «Настройки → Поисковая система».
- Автообновления нет.
- Кодеки H.264 и AAC. На них действуют патентные лицензии.

## Требования

Windows 10 или 11, 64 бит.
