# Visibility Browser 3.0.1

Первый обычный выпуск на Chromium. Если вы ставили 3.0.0, обновитесь поверх: настройки сохранятся.

## Что изменилось

- **Своё имя везде.** В диспетчере задач, свойствах файла и установщике теперь «Visibility Browser», компания GOmp Studios. Раньше там стояло «Chromium».
- **Своя иконка** у вкладки «Новая вкладка» вместо логотипа Chromium.
- **Подсказки адресной строки** рисуются внутри окна и не залипают при наборе.
- **Меньше сервисов Google.** Выключены Gemini, режим ИИ в адресной строке, Lens, подсказки покупок и поиск по истории через ИИ. Убраны поиск устройств Cast в сети и помощник Google Meet.
- В русском интерфейсе оставшиеся «Chromium» заменены на «Visibility».

## Известные ограничения

- Окна «Поиск по странице» и «Поиск по вкладкам» нарисованы Chromium в нашей палитре, формы у них стандартные.
- Схема `chrome://` в адресной строке осталась.
- Автообновления нет.

## Требования

Windows 10 или 11, 64 бит.
