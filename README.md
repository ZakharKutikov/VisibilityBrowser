# Visibility Browser

Браузер для Windows с собственным интерфейсом и встроенным VPN. Делает GOmp Studios.

**Версия 3.0 экспериментальная.** Мы перешли с Electron на собственную сборку Chromium. Она запускается и работает, но обкатана мало: возможны вылеты и недоделки. Если нужен стабильный браузер, оставайтесь на 2.1.

## Что изменилось

До 2.1 включительно Visibility был приложением на Electron. Теперь это форк самого Chromium 158. Интерфейс окна (вкладки, адресная строка, меню, настройки, история, загрузки) мы написали заново на WebUI в тех же цветах, что и в 2.1, и сделали компактнее: две строки вместо четырёх.

- Расширения Chrome работают (из Chrome Web Store и из папки). Формат `.visibility` из 2.1 не поддерживается.
- VPN встроен в браузер: VLESS, Trojan и Shadowsocks по ссылкам и подпискам, раздельная маршрутизация. Ядро Xray скачивается с GitHub при первом включении.
- Новая вкладка встроена в браузер: часы, поиск с подсказками, ярлыки, погода по IP, недавние сайты. Работает и в инкогнито.
- Выгрузка неиспользуемых вкладок («Экономия памяти») включена по умолчанию.
- Свои иконки в панели задач, диспетчере задач и установщике.

Закладки, история и настройки из 2.1 не переносятся. Закладки можно заранее выгрузить в JSON: в 2.1 «Настройки → Экспорт закладок». Версия 3.0 ставится отдельно от 2.1, и 2.1 после этого можно удалить.

## Установка

Скачайте `Visibility-3.0.0-Setup.exe` в [Releases](https://github.com/ZakharKutikov/VisibilityBrowser/releases). Нужна 64-разрядная Windows 10 или 11. Установщик не подписан, поэтому SmartScreen может показать предупреждение.

## Что известно не работает

- Из Chromium ещё не убраны все сервисы Google: вход в аккаунт, синхронизация, Lens, Gemini. План: [chromium/design/STRIP.md](chromium/design/STRIP.md).
- Поиск по странице и поиск по вкладкам выглядят как в обычном Chromium.
- На вкладках служебных страниц (`chrome://...`) вместо нашей иконки показывается логотип Chromium.
- Сборка включает кодеки H.264 и AAC. На них действуют патентные лицензии, см. [docs/BUILD.md](docs/BUILD.md).
- Автообновления в 3.0 нет, новую версию нужно ставить вручную.

Нашли ошибку — напишите в [Issues](https://github.com/ZakharKutikov/VisibilityBrowser/issues).

## Сборка из исходников

Сам Chromium в репозитории не лежит (около 100 ГБ). Здесь только наши патчи и скрипты, которые скачивают Chromium, накладывают патчи и собирают. Полная инструкция: [docs/BUILD.md](docs/BUILD.md). Первая сборка занимает несколько часов.

```powershell
cd chromium\scripts
.\fetch.ps1 -NoHooks
.\hooks.ps1
.\apply.ps1
.\build.ps1
```

## Что в репозитории

| Путь | Что там |
|---|---|
| `chromium/patches/` | Наши правки Chromium, по теме на патч, применяются по номерам |
| `chromium/args/` | Параметры сборки: dev, installer, release |
| `chromium/scripts/` | Скрипты загрузки, сборки и генерации иконок |
| `chromium/design/` | Макет интерфейса 3.0 и план отказа от сервисов Google |
| `legacy-electron/` | Исходники 2.1 на Electron, больше не развиваются |
| `ntp-extension/` | Новая вкладка из 2.1; в 3.0 перенесена во встроенную страницу |

Патчи 0001–0021 покрывают название и цвета, окно браузера на WebUI, VPN, окно разрешений сайтов, иконки и имена установки, новую вкладку и настройки по умолчанию. Список тем смотрите по именам файлов в `chromium/patches/`.
